AI Studio for Blender

Claude chat, local models and a render studio for Blender · version 1.0.0 · macOS · Blender 5.0 or newer

Install with updates

  1. In Blender: Edit › Preferences › System › Network: turn on Allow Online Access.
  2. Drag this button into the Blender window and confirm:
AI Studio 1.0.0

Blender adds this repository and installs the add-on. New versions then show up under Preferences › Get Extensions. Or add the repository by hand (Get Extensions › Repositories › + › Add Remote Repository):
https://louisdotxyz.github.io/ai-studio-blender/index.json

Install without online access

  1. Download the zip.
  2. Drag it into the Blender window, or Preferences › Get Extensions › ⌄ › Install from Disk…

This way Blender does not look for updates.

Then

  1. Open the sidebar in the 3D viewport (N): tabs Claude and Studio.
  2. The setup card checks online access, Claude Code and the login, with one button each, and connects Claude Code and the Claude app (Cowork) to the open Blender.

You need your own Claude Code access (Claude subscription) or LM Studio for local models. Unofficial, not affiliated with Anthropic or the Blender Foundation. Source and README.
